# CineGo

CineGo helps cinephiles find people to go to the movies with. Browse films showing nearby, register interest in a specific screening, see who else is interested, make a plan, and chat inside the app.

## Run locally in VS Code

1. Install Node.js and pnpm.
2. Run pnpm install.
3. Run pnpm start.
4. Open the QR code with Expo Go, or press w for the web preview.

This portfolio build uses local device persistence and sample screening data.
